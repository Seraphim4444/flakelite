# FlakeLite — новогодний снег на рабочем столе

Бесплатная альтернатива платному Flake: живой снегопад поверх всех окон Windows,
сугробы на кромках настоящих окон, игра со снегом, украшения и открытки.
Один файл `programm.py`, без интернета и внешних картинок — вся графика рисуется кодом.

## Что умеет

- **Снег** трёх режимов: лёгкий, ровный, метель. Ветер с порывами, штрихи в метели.
- **Сугробы** на нижней кромке экрана и на верхних кромках реальных окон.
  Снег растёт, разравнивается и едет вместе с окном без отставания; при быстром
  перетаскивании немного осыпается, а при сворачивании окна падает на пол.
  Окна, закрытые другими окнами, не украшаются.
- **Курсор** разметает снежинки и бороздит сугробы.
- **Игра без режимов и кнопок**: снег сам ловит мышь только рядом с сугробом.
  Проведите по снегу — покатится снежок; три снежка рядом собираются в снеговика
  (до четырёх фигур). Клик по шару или снеговику — разобрать на снежинки,
  правая кнопка — смести снег. Шары и снеговики стоят на сугробах, едут вместе
  с окном и падают вниз, если окно свернули или смели снег из-под них.
- **Гирлянда** на верхних кромках окон, **ёлка** в углу, **счётчик** до Нового года.
- **Салют**: автоматически в новогоднюю ночь и по кнопке. **Дед Мороз**
  в высокой боярской шапке, с седой бородой и посохом вместе со **Снегурочкой**
  в голубой шубе и кокошнике изредка пролетают на санях по небу в случайную
  сторону и на случайной высоте в верхней половине экрана (олени впереди,
  как и положено).
- **Снегоуборщик** периодически проезжает по нижнему сугробу; его можно
  позвать кнопкой в панели управления или из меню трея.
- **Открытка**: снимок экрана с рамкой и поздравлением, сохраняется в
  `Изображения\FlakeLite`.
- **Зимние обои по часам**: пока FlakeLite запущена, пейзаж сам обновляется
  по времени суток — ночью тёмное небо, звёзды, луна и большие сугробы; утром
  и вечером розово-оранжевое небо; днём светлый день и подтаявшие, но не
  растаявшие до конца сугробы. Солнце и луна плавно сменяют друг друга.
  Обои включаются кнопкой, прежние можно вернуть. При выходе из программы
  зимние обои автоматически сменяются прежними. Надпись «FlakeLite · время
  суток» на обоях можно убрать галочкой «Подпись на обоях» в панели
  управления или в меню трея.
- **Автозапуск** с Windows и **панель управления** поверх окон.
- **Пауза в играх**: при полноэкранном приложении снег и панель прячутся,
  таймер полностью останавливается — в игре нагрузки нет.

## Установка из исходников

```bat
python -m pip install -r requirements.txt
```

## Запуск

```bat
python programm.py
```

Без чёрного окна консоли:

```bat
pythonw programm.py
```

Готовая сборка: `dist\FlakeLite.exe` (один файл, переносится на другой ПК).

Настройки хранятся рядом с программой в `config.json` (если каталог только для
чтения — в `%APPDATA%\FlakeLite`).

## Горячие клавиши и меню

- Иконка в трее — погода, ветер, качество, украшения, салют, Дед Мороз,
  снегоуборщик, открытка, обои, «смести снег» / «разобрать снеговиков и шары»,
  пауза, выход, а также просьба о поддержке.
- Играть можно сразу, ничего не включая: снег сам становится интерактивным,
  когда курсор оказывается над сугробом, шаром или снеговиком.
- Открытка — `F12` (если занята другой программой, автоматически `F11`).
- Панель управления можно перетащить мышью, положение запоминается.
- Кнопка «Снегоуборщик» в панели управления зовёт машину на нижний сугроб.

## Поддержать автора

FlakeLite бесплатна и останется бесплатной. Я очень старался сделать её
лёгкой, красивой и новогодней. Если она вам нравится и есть желание
поддержать автора — буду очень благодарен. Это совсем не обязательно,
программа работает и без этого. ❤

- Альфа-Банк: `2200 1530 1480 8720`
- Телефон: `+7 (904) 306-36-00`

Надпись о поддержке видна в панели управления. Её можно скрыть галочкой
«Показывать просьбу о поддержке» в панели управления или в меню трея.
В трее есть пункт «❤ Поддержать автора» с этими реквизитами и кнопкой
«Скопировать номер карты».

## Параметры командной строки

```
--fps                 счётчик кадров
--weather light|steady|blizzard
--wind -1..1          ветер
--density 0.2..2      плотность снега
--quality 20|30|60    целевой FPS
--no-hud              без панели
--no-pause            не прятаться в полноэкранных приложениях
--exit-after N        выйти через N секунд (для проверок)
--reset-config        сбросить настройки
```

## Сборка exe

```bat
build_exe.bat
```

Скрипт поставит PyInstaller и соберёт `dist\FlakeLite.exe` с иконкой `flake.ico`.

## Требования

Windows 10/11, Python 3.10+ и PySide6 (`python -m pip install PySide6-Essentials`).
Для запуска собранного exe Python не нужен.
